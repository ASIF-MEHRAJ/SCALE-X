ScaleX Insights & Blogs
A high-end, dark-themed blog portal designed for SaaS and tech-forward brands. This project focuses on minimalist aesthetics, Glassmorphism, and a seamless user experience.

🚀 Overview
ScaleX Insights is a responsive blog landing page that showcases a clean, modern approach to content delivery. It features a dynamic category filtering system and a premium card-based layout designed to maximize engagement and readability.

✨ Key Features
Modern UI/UX: Dark-mode primary theme with high-contrast orange accents.

Glassmorphic Design: Card components featuring subtle blurs and transparency.

Responsive Grid: A fully fluid layout that adapts from desktop to mobile flawlessly.

Interactive Elements: Smooth hover transitions and custom-styled filter buttons.

Professional Typography: Optimized for readability using high-end font pairings.

🛠️ Tech Stack
HTML5: Semantic structure for SEO and accessibility.

CSS3: Custom properties (variables), Flexbox, and CSS Grid.

JavaScript: Logic for category filtering and interactive UI components.

Icons: Lucide-React / FontAwesome integration.
